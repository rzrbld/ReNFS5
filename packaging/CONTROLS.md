# Controls

Use the D-pad to select launcher options, Left/Right to change them, A to
confirm, and B to return or exit. Controller mapping is available in settings.

## In the race (default mapping)

| Action | Button |
|---|---|
| Steer | Left stick (analog) or D-pad left/right (full lock) |
| Throttle | R1 or R2 |
| Brake / reverse | L1 or L2 |
| Handbrake | A |
| Shift up / down (manual gearbox) | B / X |
| Change camera | Y |
| Horn | Right stick click |
| Pause | Start |

The game drives player 1 with its own joystick bindings; the port presents the
handheld as that joystick, built from the launcher's CONTROLLER MAPPING page
(configs/controller.cfg). R2/L2 are digital on these devices, so they act as
full throttle/brake. B also works as "back" (Escape) in menus.

## Menus

The left stick moves the mouse cursor and A clicks; the D-pad sends arrow keys,
A is Enter and B/Start is Escape.

Keyboard (desktop): arrows drive, Enter confirms, Escape pauses, Space is the
handbrake and C changes the camera.

Save files live in saves/ and controller configuration in configs/controller.cfg.
